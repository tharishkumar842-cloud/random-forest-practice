# Random Forest Customer Purchase Prediction

## About
This project uses a Random Forest Classifier to predict whether a customer will purchase a product based on customer details and website activity.

## Technologies
- Python
- Pandas
- Scikit-learn

## Features
- Creates a customer dataset using Pandas
- Splits data into training and testing sets
- Trains a Random Forest Classification model
- Evaluates the model using accuracy, classification report, and confusion matrix
- Predicts purchases for new customers
- Displays prediction probabilities
- Identifies important features using feature importance

## Input Features
- Age
- Income
- Previous Purchases
- Website Time
- Clicked Ad

## Target
`Purchased`
- `0` — Not purchased
- `1` — Purchased

## How to Run

Install the required libraries:

```bash
pip install pandas scikit-learn
```

Run the Python file:

```bash
python customer_purchase_prediction.py
```

- Training a classification model
- Evaluating model performance
- Making predictions on new data
